# 岗位采集助手（BOSS直聘 / 前程无忧）

一个带图形界面的招聘岗位采集工具，支持 **BOSS直聘（zhipin.com）** 与 **前程无忧（51job.com）** 两个网站。通过 Chrome 调试模式自动操作页面 + 监听岗位列表接口，采集岗位信息并导出为 CSV，支持多条件筛选、岗位详情查看。

## 功能特性

- **双站采集**：界面顶部可切换「BOSS直聘」或「前程无忧(51job)」，两家网站城市代码体系不同，切换后城市下拉框会自动对应
- **主题配色**：BOSS直聘 使用蓝色主题；切换到前程无忧 后，界面涉蓝部分自动变为橙红色（#FF6314）
- **自动采集**：连接调试模式的 Chrome，监听岗位列表接口，自动翻页采集多页数据
- **随时停止**：采集过程中可点「停止采集」按钮中断，当前页/当前岗位处理完后自动收尾
- **图形界面**：基于 customtkinter 的现代风格界面，无需写代码即可操作
- **多条件筛选**：
  - 单选下拉：规模、学历要求、经验要求、技能需求、省市区
  - 点击多选（内联下拉，就地勾选）：公司领域、薪资、福利待遇
  - 筛选只作用于界面列表的实时显示；开始新采集时会自动重置筛选条件
- **详情查看**：点击列表中的岗位即可查看完整信息
- **一键导出**：导出选中 / 全部岗位 / 当前筛选列表 三种方式，支持自定义导出目录（自动记住）
- **全国城市**：BOSS直聘 自动加载全国城市数据，可手动输入任意城市；前程无忧 内置 378 个城市编码。城市下拉框只显示一二线城市前 20 个，其余城市可在右侧输入框手动输入
- **技能预设**：按岗位关键词自动刷新技能需求预设选项
- **日志滚动**：运行日志按日期保存到 `logs/` 目录，方便排查问题

## 环境要求

- Windows 系统
- Python 3.8+
- Chrome 浏览器
- 需要安装依赖：

```bash
pip install DrissionPage customtkinter
```

## 使用方法

1. **以调试模式启动 Chrome**（命令行执行）：

   ```
   chrome.exe --remote-debugging-port=9222
   ```

   > 提示：先关闭所有已打开的 Chrome 窗口再执行，否则可能不生效。

2. **运行本程序**：

   ```bash
   python boss_zhipin_collector_fixed.py
   ```

   > `boss_zhipin_collector_fixed.py` 为修复版（推荐），修复了筛选卡死、薪资解析、导出逻辑等问题；`boss_zhipin_collector.py` 为原始版本。

3. 在 Chrome 中登录对应网站：采 BOSS直聘 需先登录（未登录或触发验证码会没有数据）；采 前程无忧 一般可匿名浏览，但若触发滑块验证码也需要登录。

4. 在界面顶部选择**采集网站**（BOSS直聘 / 前程无忧(51job)），然后选择**城市**、填写**岗位关键词**、设置**采集页数**，按需配置**筛选条件**。

5. 点击「开始采集」，后台自动采集并写入 CSV，界面列表实时更新；采集过程中可点右侧「停止采集」中断。

6. 采集完成后可点选查看详情，或用「导出选中的 / 全部 / 当前列表」按钮导出数据。

## 生成的 CSV 说明

| 文件 | 说明 |
| --- | --- |
| `boss_城市_关键词_日期.csv` | 采 BOSS直聘 时生成的原始结果（全部岗位，不按筛选过滤） |
| `51job_城市_关键词_日期.csv` | 采 前程无忧 时生成的原始结果（全部岗位，不按筛选过滤） |
| `导出岗位_日期.csv` | 通过「导出」按钮导出的结果（选中 / 全部 / 当前列表） |
| `设置.json` | 保存的用户偏好（如导出目录），自动生成 |
| `logs/运行日志_日期.txt` | 按日期滚动的运行日志 |

每条岗位包含字段：岗位名称、公司、规模、公司领域、学历要求、经验要求、技能需求、福利待遇、薪资、薪资原文、省、市、区、商圈、经纬度、岗位链接、jobId。两站的薪资会统一折算为「月薪数值」用于筛选（前程无忧的年薪会自动除以 12）。

## 常见问题

- **采集无数据**：请确认已用调试模式启动 Chrome、已登录对应网站（BOSS直聘需登录），并查看日志区提示。
- **前程无忧城市不在下拉框**：城市下拉框只显示一二线城市前 20 个，其余城市直接点「选城市」右侧输入框手动输入即可；若输入的县级及以下城市不在内置 378 个编码里，可先在浏览器切换到该城市后从地址栏 `jobArea=` 获取编码，再补充到脚本 `CITY_51JOB_OPTIONS`。
- **文件被 Excel 占用**：导出时会自动改用带序号的新文件名，不会覆盖失败。
- **推送/访问 GitHub 慢**：请为 git 配置代理（国内网络直连 GitHub 不稳定）。
