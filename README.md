# BOSS直聘 岗位采集助手

一个带图形界面的 BOSS直聘（zhipin.com）岗位采集工具。通过 Chrome 调试模式自动操作页面 + 监听岗位列表接口，采集岗位信息并导出为 CSV，支持多条件筛选、岗位详情查看。

## 功能特性

- **自动采集**：连接调试模式的 Chrome，监听岗位列表接口，自动翻页采集多页数据
- **图形界面**：基于 customtkinter 的现代风格界面，无需写代码即可操作
- **多条件筛选**：
  - 单选下拉：规模、学历要求、经验要求、技能需求、省市区
  - 点击多选（内联下拉，就地勾选）：公司领域、薪资、福利待遇
  - 采集时即按当前筛选条件过滤，生成的 CSV 只包含符合条件的数据
- **详情查看**：点击列表中的岗位即可查看完整信息
- **一键导出**：导出选中岗位或当前筛选结果，支持自定义导出目录（自动记住）
- **全国城市**：自动加载 BOSS直聘全国城市数据，可手动输入任意城市
- **技能预设**：按岗位关键词自动刷新技能需求预设选项
- **日志滚动**：运行日志按日期保存到 `logs/` 目录，方便排查问题

## 环境要求

- Windows 系统
- Python 3.8+
- Chrome 浏览器
- 需要安装依赖：

```bash
pip install DrissionPage customtkinter
```

## 使用方法

1. **以调试模式启动 Chrome**（命令行执行）：

   ```
   chrome.exe --remote-debugging-port=9222
   ```

   > 提示：先关闭所有已打开的 Chrome 窗口再执行，否则可能不生效。

2. **运行本程序**：

   ```bash
   python boss_zhipin_collector.py
   ```

3. 在 Chrome 中登录 BOSS直聘（未登录或触发验证码会采不到数据）。

4. 在界面中选择**城市**、填写**岗位关键词**、设置**采集页数**，按需配置**筛选条件**。

5. 点击「开始采集」，后台自动采集并写入 CSV，界面列表实时更新。

6. 采集完成后可点选查看详情，或点击「导出全部岗位」导出筛选后的结果。

## 生成的 CSV 说明

| 文件 | 说明 |
| --- | --- |
| `boss_城市_关键词_日期.csv` | 采集过程中生成的原始结果（已按采集时的筛选条件过滤） |
| `导出岗位_日期.csv` | 通过「导出」按钮导出的结果（当前列表可见的岗位） |
| `设置.json` | 保存的用户偏好（如导出目录），自动生成 |
| `logs/运行日志_日期.txt` | 按日期滚动的运行日志 |

每条岗位包含字段：岗位名称、公司、规模、公司领域、学历要求、经验要求、技能需求、福利待遇、薪资、薪资原文、省、市、区、商圈、经纬度、岗位链接、jobId。

## 常见问题

- **采集无数据**：请确认已用调试模式启动 Chrome、已登录 BOSS直聘，并查看日志区提示。
- **文件被 Excel 占用**：导出时会自动改用带序号的新文件名，不会覆盖失败。
- **推送/访问 GitHub 慢**：请为 git 配置代理（国内网络直连 GitHub 不稳定）。
